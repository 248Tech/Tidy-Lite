# Changelog

## v1.0.0 (2026-11-17)

First public release. A native, 111 KB sibling of [Tidy](https://github.com/248Tech/Tidy).

- Overview: processor, memory and system-drive gauges in plain English, plus the apps using the most memory.
- Apps: processes grouped by app with icons, live memory and CPU, Close or Force quit, protection for critical Windows processes.
- Storage: scan a drive or folder, drill into folders, biggest-files list, delete to Recycle Bin with Undo (Shift = delete forever).
- Clean up: temp files, browser caches, crash reports, thumbnail cache, Recycle Bin.
- Follows the Windows light/dark setting, DPI-aware, `--page N` and `--scan <folder>` options.
